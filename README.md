# Monthly Expense Recorder

A simple, single-page web application to help you track your monthly expenses. Easily record expenses with an amount and category, and have them persistently saved in your browser's local storage.

## Features

*   **Expense Input:** Quickly add new expenses by entering an amount and a category.
*   **Persistent Storage:** All your expenses are automatically saved to your browser's LocalStorage, so they remain even if you close and reopen the browser.
*   **Expense Listing:** View all your recorded expenses in a clear, scrollable list.
*   **Delete Functionality:** Remove individual expenses if needed.
*   **Responsive Design:** A clean and simple interface that works well on various screen sizes.

## How to Run

This application is designed as a static HTML file, making it very easy to run.

1.  **Save Files:** Download all the provided files (`index.html`, `script.js`, `style.css`, `README.md`, `LICENSE`) into a single folder on your computer.
2.  **Open in Browser:** Simply open the `index.html` file with your preferred web browser (e.g., Chrome, Firefox, Edge). You can usually do this by double-clicking the `index.html` file.

That's it! The application will load, and you can start recording your expenses immediately.

## Usage

1.  **Enter Amount:** In the "Amount" field, type the numerical value of your expense (e.g., `50.00`).
2.  **Enter Category:** In the "Category" field, type a descriptive category for your expense (e.g., `Groceries`, `Rent`, `Utilities`, `Entertainment`).
3.  **Add Expense:** Click the "Add Expense" button. The new expense will appear in the list below.
4.  **Delete Expense:** To remove an expense, click the "Delete" button next to the expense item you wish to remove. A confirmation prompt will appear.
5.  **Persistence:** Your expenses are saved automatically after each addition or deletion. If you close your browser or navigate away and come back, your expenses will still be there.

## Technologies Used

*   **HTML5:** For the structure of the web page.
*   **CSS3:** For styling and layout.
*   **JavaScript (ES6+):** For application logic, user interaction, and LocalStorage management.
